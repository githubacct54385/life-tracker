Life Tracker: Desktop Wireframes v0.1

CSV import is desktop-only, because the bank files live on the desktop. These screens show the wide layout for importing and for browsing transactions. Everything else in the app uses the phone layout as the default and simply scales up. All names and numbers are fake.

Things to react to

  • Desktop navigation: a left sidebar instead of the phone's bottom tabs. Same five areas, with Money expanded.
  • Edit panel: side panel (shown) or a popup over the table?
  • Duplicates: skipped automatically (shown). Do you also want a "import anyway" toggle for rare legitimate repeats, like two identical coffee purchases in one day?
  • Mobile: the Import button is hidden on phones. Should the phone show a message about importing from a computer, or just nothing?
